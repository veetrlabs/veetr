## Photo prompt set

Shared prompt: Use case: lighting-weather. Edit target: supplied documentary hardware photo for a development timeline. Professional restrained photographic correction: neutral white balance, balanced exposure, gentle local contrast and clarity, natural colors. Keep exact physical hardware, wires, connectors, geometry, printed text and imperfections unchanged. Do not redesign, invent or replace anything. Tighter landscape composition where possible without cutting the main hardware. No added text, no border, no watermark.

- breadboard.png: Reduce the strong yellow indoor cast; emphasize the wired breadboard, crop out most empty desk and lamp.
- pcb.png: Emphasize the complete black PCB with all four corners visible; retain all silkscreen text exactly, subtly reduce warm desk cast.
- case.png: Keep the entire blue 3D printed enclosure and attached antenna visible. Lift shadows gently, reduce noise, preserve imperfect embossed Veetr lettering and real print texture.

AI photo edits are presentation assets, not references for wiring, dimensions or PCB markings. Refer to the original design files for technical details.

real-world-testing.jpg and display-prototype.png are the supplied originals, preserved without generative edits so readings, reflections and prototype details remain documentary evidence. Astro provides the same responsive WebP sizing.
