---
title: "Series managers"
description: "Set up a series, its races, fleet, scoring, and officials."
---

A series manager configures an assigned series and can also perform the referee’s race-day tasks. The series owner retains management access.

## Create or open a series

1. Sign in and open [race management](/races/manage/).
2. Open an existing series, or choose **New series** if your account has series creation access.
3. Set the name, season, categories, and series discard rules.
4. Save, then open the series.

Managing an existing series does not automatically allow you to create new ones. If creation is unavailable, request creation access through your account and wait for administrator approval.

## Build the fleet

Open the series **Fleet** tab. Select existing boats from the registry before creating new ones, so a boat’s history stays together. Assign each boat to its category for this series.

Create a boat if it is missing. An organiser-created boat can await handover to a responsible skipper. Use the boat’s access page to arrange that handover; signing in alone does not claim a boat. See [Skippers](/docs/race-skippers/).

Register boats for each race in its **Fleet** tab. Check the heat entries before recording finishes, particularly if the fleet changed after racing began.

## Configure races and heats

1. In **Races**, create a race and set its scheduled start.
2. Set **Starting points** and any heat discard rules for that race.
3. Open the race’s **Heats** tab and create the required heats.
4. Check each heat’s entries and whether its results are shared.

Starting points belong to the race, not its heats. Leave the default at 0 unless your competition uses another value. For example, −1 gives the race winner −1 series point, second place 0, and third place 1. See [Scoring and results](/docs/race-scoring/).

Mark the race completed when appropriate: completed races determine when series discards become available.

## Give officials access

Use the series team controls to add registered teammates by email. Give **Series manager** access to someone configuring the event and **Referee** access to someone recording results and operating tracking. Series-team membership changes do not send a boat invitation; ask a new official to sign in first.

These permissions concern this series. Platform user management belongs to [administrators](/docs/race-administrators/).

## Run the event

Follow the [referee workflow](/docs/race-referees/) for finishes, corrections, and tracking. Use one primary device and browser tab for finish entry, check that changes have synced, and export backups at suitable breaks.
